## API and private boundary
`createSdkProcessAuthority({broker,issuer,registry,lifecycle,recipientPage,sender,recipient,originalReceipt,transferId,bindingId,signal,deadline,terminateOwnedChannel})` returns frozen `{authorize,close}`. Each participant is exactly `{userId,matrixDeviceId,deviceId,accessToken}`; `matrixDeviceId` is the Matrix SDK ID, `deviceId` the enrolled native ID. Original receipt must be the actual detached SDK `transportExport` receipt already exported by the real trusted driver. `recipientPage` is its current live recipient page. Deadline is an absolute millisecond timestamp, no more than five seconds ahead; `signal` must be a live AbortSignal.

The driver supplies its concrete real broker/issuer/registry/lifecycle instances, not grant booleans or mock authority closures. JavaScript cannot attest those supplied objects' provenance: passing substitutes does NOT establish actual authentication. Only independently inspected actual SDK/native CI execution can prove the adapter was wired to those real objects. The candidate never treats an injected boolean as a lease or receipt, and has no cached-grant/mockAllowed API.

`authorize(request,abortSignal)` matches `openCiphertextSession` callback and returns ONLY a strict boolean. The closure retains tokens, original receipt and descriptor key in parent RAM. They must never be spread into the IPC manifest, child options, logs or artifacts. New child generation gets a NEW adapter; command/request/checkpoint order and transfer/binding identifiers are latched. Initial capture is denied unless both real native sessions, two active immutable registry pins, and SDK event receipt validate. Each callback repeats all checks, with fresh native whoami + broker resolution for BOTH participants, exact initial pin equality (native ID/user/Matrix device/Ed25519/Curve25519), same fixed room, lifecycle active state, and existing genuine SDK receipt gates. Native sessions and exact pins are refreshed again after SDK awaits. Every await has pre/post deadline/abort/closed checks. Any failure permanently denies the adapter and initiates owned channel shutdown.
